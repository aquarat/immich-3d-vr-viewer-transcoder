Immich VR step 1 · capability probe

Answers three questions before any viewer gets written: does this browser expose WebXR media layers, will it decode the 3840×1080 HEVC camcorder footage, and does the Immich API authenticate from this origin.

1 · Immich API access

Video elements cannot send an x-api-key header, so playback relies on the same-origin Immich session cookie. Log into Immich in this browser first. The key is only used for fetch() probes, and to test whether query-string auth is accepted.
